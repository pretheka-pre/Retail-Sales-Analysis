# Retail Sales Analysis Project

## Overview
This project analyzes retail sales data using Python to extract meaningful business insights such as product performance, revenue trends, and sales distribution patterns. The objective is to transform raw transactional data into actionable insights for decision-making.


## Objective
The goal of this project is to perform exploratory data analysis (EDA) on retail sales data to understand:
- Top-performing products
- Revenue contribution by product
- Sales quantity patterns
- Key insights to support business decisions



## Tools and Technologies
- Python
- Pandas for data manipulation and analysis
- Matplotlib for data visualization
- Seaborn for advanced visualization
- Jupyter Notebook for development



## Project Structure
- notebooks/ : Jupyter notebook containing the analysis
- data/ : Dataset used for analysis
- README.md : Project documentation



## Analysis Performed
- Data loading and inspection
- Feature engineering (Revenue calculation)
- KPI calculations (total revenue, total quantity, average revenue)
- Product-wise revenue analysis
- Product-wise quantity analysis
- Revenue distribution analysis



## Key Insights
- A small number of products contribute the majority of revenue
- High sales volume does not always correspond to high revenue
- Revenue is unevenly distributed across products
- Identifying top products helps improve business strategy



## Conclusion
This project demonstrates how raw retail data can be transformed into structured insights using Python. It highlights the importance of data analysis in understanding sales patterns and supporting business decisions.
