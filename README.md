# Retail Sales Analysis Project

## Overview
This project analyzes retail sales data to understand product performance and revenue trends.

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Key Insights
- Identified top revenue-generating products
- Analyzed quantity vs revenue relationship
- Discovered sales distribution patterns

## Project Structure
- notebooks/ → analysis notebook
- data/ → dataset
- reports/ → insights summary
